# ユドナリウム・トマホーク

**Udonarium Tomahawk** は、ブラウザ上で動作するオンラインTRPGセッションツールです。

ユドナリウム系の操作性と軽量さを維持しながら、視界・照明・Fog of Warなど、マップを使用したセッション向けの機能を拡張しています。

## バージョン

現在のバージョン：**1.0.0**

## 主な特徴

- ブラウザベースのオンラインTRPG環境
- P2Pによるルーム接続
- キャラクター・マップ・チャット・ダイスボット
- 光源と壁を利用した視界判定
- 通常視界・暗視・上位暗視
- Advancedモード
- Fog of War（探索済み領域）
- Fog of Warの参加者間共有
- 探索済み領域の保存・復元
- ジュークボックスによるBGM再生
- VN Stage
- SkyWayを利用した通信

## Fog of War

AdvancedモードではFog of Warを使用できます。

キャラクターが一度視認した領域は「探索済み領域」として記録され、現在視認できない場所についても暗く表示されます。

探索履歴は同じ卓の参加者間で共有されます。

## 起動方法

### 通常起動

Windowsでは、

`start-tomahawk.bat`

を実行します。

### 開発用起動

`dev-tomahawk.bat`

を実行すると、ビルド後にTomahawkを起動します。
